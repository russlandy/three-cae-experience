# Фиксированный диапазон легенды и пороги по физике

По умолчанию палитра растянута на фиксированный диапазон 20–1600 °C, а на легенде стоят отметки физических порогов стали: 1500 °C (плавление, граница зоны сплавления), ≈900 °C (Ac3) и ≈720 °C (Ac1) — границы зоны термического влияния. Режим «авто (min–max текущего шага)» оставлен переключателем, но не по умолчанию: при автоматическом растяжении цвет перестаёт означать одну и ту же температуру между шагами времени и между расчётами — остывшая до 220 °C пластина выглядит такой же «жёлтой», как сварочная ванна, и сравнивать картинки нельзя.

## Consequences

- Значения выше 1600 °C показаны верхним цветом палитры (насыщение) — внутри ванны различий не видно, это осознанно: всё выше плавления — жидкий металл.
- Пороги — константы для стали; для другого материала их надо менять (это данные материала, а не настройка отображения).
